# comic-ui — Attorney Assistant comic-book design system

Standalone React + TypeScript component library that houses all comic-book-themed UI primitives (burst badges, skyline headers, bat-signal CTAs, action panels, etc.) used across Attorney Assistant hero/campaign landing pages. Components are built with Vite library mode and ship as a pure ES module so they can be consumed by both the main Astro site and any future React app. See `docs/superpowers/plans/2026-06-24-comic-design-system.md` for the full design plan.
